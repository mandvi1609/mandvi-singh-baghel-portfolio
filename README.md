# Mandvi Singh Baghel — Luxury Marketing Portfolio

A one-page, editorial-style portfolio for luxury & premium brand marketing.

**Sections:** About Me · Skills & Certificates · Projects (Apple Premium Retail, SafarCabby Brand Playbook, Rush4Rush Event Experience, Akriti Fabrication) · Beyond the Brief · Get in Touch

## View it
Open `index.html` in a browser, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Add your photo
Put your photo at `assets/photo.jpg`, then in `index.html` replace the `<span class="photo-initials">MSB</span>` inside `.photo` (and the polaroid) with:

```html
<img src="assets/photo.jpg" alt="Mandvi Singh Baghel">
```
