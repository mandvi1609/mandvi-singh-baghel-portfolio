# Mandvi Singh Baghel — Luxury Marketing Portfolio

A one-page, editorial-style portfolio for luxury & premium brand marketing.

**Sections:** About Me · Skills & Certificates · Projects (Apple Premium Retail, GSB — Global Shirt Box, SafarCabby Brand Playbook, Rush4Rush Event Experience, SMART Project, Akriti Fabrication) · Beyond the Brief · Get in Touch

## View it
Open `index.html` in a browser, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Photos
- `assets/mandvi-campus.jpg` (About Me) and `assets/mandvi-portrait.jpg` (Get in Touch polaroid)
- Project photos live in `assets/projects/` as `<project>-NN.jpg` (full size) and `<project>-NN-sm.jpg` (thumbnail).
  The list of photos for each project folder is the `GALLERIES` object at the top of `script.js`.
